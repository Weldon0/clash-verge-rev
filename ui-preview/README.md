# UI preview 02

A standalone interactive design proposal using local sample data. It does not call the proxy core or send subscription links.

Run `node ui-preview/serve.mjs` and open http://127.0.0.1:4175.

Navigation, filters, node selection, subscription creation, themes and preferences are interactive. Press 1–8 to navigate, D to switch theme and / to search.

Apply the approved design to the native client before producing a new desktop bundle.
